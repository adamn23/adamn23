# Hey, I’m Adam

Computer Science student at the University of Toronto with an interest in systems programming, operating systems, and software infrastructure. I enjoy building reliable, performance-oriented software and exploring the parts of computing that sit beneath modern abstractions.
My most recent project is Morpheus, a local-first research platform for studying whether carefully timed auditory cues can increase lucid dream frequency. The project emphasizes reproducible experimentation over optimistic claims, featuring a blinded randomized N-of-1 trial framework, adaptive experimentation, strict safety constraints, and validation gates that prevent unverified features from being used. It deliberately avoids claiming capabilities it cannot scientifically support.
Most of my work is in C, C++, Rust, Python, and Linux, with interests spanning kernels, networking, compilers, distributed systems, and systems architecture.
